## Design a Notification Engine

### Functional Requirements
- **Plug and Play Model**: User can integrate the service with any application with minimal code changes
- **Highly Extensible**: SMS, Email, Popup, etc.
- **Notification should be highly extensible Dynamically**.
- **Store all notifications**
- **Logging**

### Non-Functional Requirement
- Each part of the design should be **scalable & Modifiable**
- Should follow all **design principles** properly
- Design should be **highly extensible**
- Support all the above features
